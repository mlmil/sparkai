🚀 Quick Setup

Get started in 3 simple steps:

  • Click the orange chat button
  • Start chatting immediately

✨ Features

  • AI-powered responses
  • Context-aware conversations
  • Typing indicators
  • Message history
  • Responsive design
  • Smooth animations

🎨 Customizable

  • Change colors and themes
  • Modify system prompts
  • Adjust position
  • Configure AI parameters
  • Add custom features
// Example: Customize the system prompt
window.geminiChat = new GeminiChat({
  systemContext: `You are a helpful assistant for [YOUR COMPANY].`
});

// Example: Change chat position (in CSS)
.gemini-chat-widget {
  bottom: 2rem;
  left: 2rem; /* Move to left side */
}

// Example: Adjust AI creativity
generationConfig: {
  temperature: 0.9, /* Higher = more creative */
  maxOutputTokens: 2048
}
